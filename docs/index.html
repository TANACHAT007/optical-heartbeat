Optical Heartbeat Detector

เครื่องวัดชีพจรด้วยแสงอินฟราเรด (IR LED + phototransistor → LM358 → Arduino) · Mini-project 1/2026 · ออกแบบและจำลองแล้ว ยังไม่ได้ต่อวัดกับของจริง

เครื่องจำลองชีพจร
ปรับแสงสะท้อน ชีพจร และ VR ดูสัญญาณทุกจุดและอ่าน BPM ต่อวงจรบนเบรดบอร์ด
วงจรที่ต่อเสร็จ เห็นกระแสไฟวิ่ง กราฟ และลองต่อเองพร้อมมัลติมิเตอร์ วงจร 3 มิติ
หมุนดูวงจรบน breadboard ชี้ดูชื่อชิ้นส่วน โค้ดและไฟล์ทั้งหมดบน GitHub
